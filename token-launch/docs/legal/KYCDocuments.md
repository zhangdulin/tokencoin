## 概述

KYC (Know Your Customer) 是反洗钱 (AML) 合规的基本要求。所有代币购买者必须完成 KYC 验证。

---

## 1. 个人投资者 KYC

### 1.1 必需文件

| # | 文档类型 | 说明 | 状态 |
|---|---------|------|------|
| 1 | 有效身份证件 | 护照/身份证/驾照 | [ ] |
| 2 | 地址证明 | 3个月内水电费账单/银行账单 | [ ] |
| 3 | 照片 | 手持证件的自拍 | [ ] |

### 1.2 身份证件要求

```
有效身份证件包括：
- 护照 (首选)
- 身份证 (双面)
- 驾照 (双面)

要求：
- 清晰可读
- 未过期
- 包含照片和姓名
```

### 1.3 地址证明要求

```
接受的地址证明：
- 银行对账单 (3个月内)
- 水电费账单 (3个月内)
- 电话账单 (3个月内)
- 租房合同

不接受：
- 手机截图
- 互联网账单
- 邮政信箱地址
```

| 1 | 公司注册证明 | 营业执照或注册证书 | [ ] |

| 6 | 地址证明 | 公司注册地址证明 | [ ] |

### 2.2 实益拥有人 (UBO) 信息

```
需要提供直接或间接持有公司 10% 以上股份的个人信息：
- 全名
- 国籍
- 出生日期
- 身份证件
- 地址证明
- 持股比例
```

## 4. 反洗钱 (AML) 筛查

### 4.1 制裁筛查

投资者必须通过：

- [ ] OFAC 制裁名单筛查
- [ ] UN 制裁名单筛查
- [ ] EU 制裁名单筛查
- [ ] 恐怖主义融资名单筛查

### 4.2 负面新闻筛查

- [ ] 无不良媒体记录
- [ ] 无犯罪调查记录
- [ ] 无破产记录

## 6. 文件提交指南

### 6.1 文件格式要求

```
图片格式：JPG, PNG, PDF
文件大小：每份不超过 10MB
图片质量：清晰可读，无遮挡
有效期：证件必须在有效期内
```

### 6.2 提交方式

1. 通过 KYC 平台上传
2. 发送至 kyc@tokencoin.com
3. 通过安全文件传输服务

### 6.3 安全注意事项

- 不要向未经授权的人员提供文件
- 确保提交渠道安全
- 保留文件副本
- 注意个人隐私保护

## 7. KYC 审核流程

### 7.1 审核时间线

| 阶段 | 时间 | 说明 |
|------|------|------|
| 文件提交 | 即时 | 提交所有必需文件 |
| 初审 | 1-2 工作日 | 检查文件完整性 |
| 复审 | 2-3 工作日 | 进行 AML 筛查 |
| 结果通知 | 3-5 工作日 | 通知审核结果 |

### 7.2 审核状态

| 状态 | 说明 |
|------|------|
| 待审核 | 文件已提交，等待审核 |
| 补充材料 | 需要提供额外文件 |
| 审核中 | 正在深入审核 |
| 通过 | KYC 验证通过 |
| 拒绝 | KYC 验证失败 |
