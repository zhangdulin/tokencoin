## 6. 风险披露

### 6.1 风险因素

购买方理解并承认以下风险：

1. **价格波动风险**: 代币价格可能剧烈波动
2. **流动性风险**: 可能无法随时变现
3. **智能合约风险**: 合约可能存在未知漏洞
4. **监管风险**: 法规变化可能影响项目
5. **技术风险**: 区块链网络可能中断
6. **团队风险**: 团队可能发生变化

### 6.2 风险自担

```
购买方确认:
- 投资决定完全基于个人判断
- 已充分了解投资风险
- 自行承担投资损失
- 不向发行方追究投资损失责任
```
