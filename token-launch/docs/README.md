## 快速开始

### ⭐ 首次使用必读

**如果你是第一次接触这个项目，请先阅读:**
```
docs/GETTING_STARTED.md
```

这个文件包含:
- GitHub 仓库创建和提交完整教程
- 审计申请流程
- 下一步行动清单
- 常见问题解答

### 1. GitHub 仓库 (第一步)

1. 阅读 `GETTING_STARTED.md` 第 1 部分
2. 创建 GitHub 仓库
3. 推送代码

### 2. 审计申请

1. 查看 `audit/audit-application-form.md` 填写申请表
2. 使用 `audit/email-templates.md` 中的模板发送邮件
3. 或直接使用 `audit/email-to-certik.txt` 发送给 CertiK

### 3. 法律准备

1. 查看 `legal/legal-data-package-checklist.md` 准备文件
2. 根据需要使用 `legal/TokenPurchaseAgreement.md` 模板
3. 确保完成 KYC 流程 (`legal/KYCDocuments.md`)

### 4. 市场推广

1. 参考 `marketing/whitepaper.md` 完善白皮书
2. 准备其他市场营销材料

## 如何使用这些文档

### 审计申请流程

```
1. 准备阶段
   ├── 填写审计申请表
   ├── 整理合约源代码
   ├── 准备项目白皮书
   └── 准备代币经济学文档

2. 联系阶段
   ├── 选择审计机构
   ├── 发送申请邮件
   ├── 提供补充材料
   └── 获取报价

3. 签约阶段
   ├── 确认审计范围
   ├── 签署 NDA
   ├── 签署审计合同
   └── 支付预付款
```

### 法律准备流程

```
1. 确定法律实体
   ├── 选择注册地
   ├── 完成公司注册
   └── 获取注册证明

2. 准备法律文件
   ├── KYC 文件
   ├── 购买协议
   ├── 风险披露
   └── 隐私政策

3. 获取法律意见
   ├── 联系律所
   ├── 提交法律数据包
   └── 获取书面意见
```
