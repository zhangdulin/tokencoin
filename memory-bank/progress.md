## 测试网部署配置要求

### 必需配置项

| 配置 | 用途 | 获取方式 |
|------|------|---------|
| `SEPOLIA_RPC_URL` | Sepolia 测试网 RPC | [Alchemy](https://www.alchemy.com/) 或 [Infura](https://www.infura.io/) 免费注册 |
| `PRIVATE_KEY` | 部署私钥 | 测试网钱包私钥 (只用测试币) |
| `ETHERSCAN_API_KEY` | 合约验证 | [etherscan.io](https://etherscan.io/apis) 免费申请 |
| `BSCSCAN_API_KEY` | BSC 合约验证 | [bscscan.com](https://bscscan.com/apis) 免费申请 |

### 测试网水龙头

| 网络 | 水龙头 |
|------|--------|
| Sepolia | https://sepoliafaucet.com/ |
| BSC Testnet | https://www.bnbchain.org/en/testnet-faucet |

### 测试网部署命令

```bash
# 1. 编辑 .env 文件填入真实配置
vim token-launch/.env

# 2. 部署到 BSC Testnet (已有公开 RPC)
npx hardhat run scripts/deploy-token.js --network bscTestnet

# 3. 验证合约
npx hardhat run scripts/verify-contract.js --network bscTestnet
```
